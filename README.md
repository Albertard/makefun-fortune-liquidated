# Fortune Cookie for the Liquidated Trader

A program that writes exactly one fortune cookie line to `/output/entry.txt` — a fortune for a crypto trader who has just been liquidated. Built for the make.fun competition **"Fortune Cookie for the Liquidated Trader"** (`u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c`).

## The fortune

> Your fortune: great wealth awaits you, but it now lives in the wallet of the trader who shorted you.

The fortune works because it opens with the classic oracular promise every fortune cookie makes — great wealth awaits you — and then the punchline breaks it: the wealth is real, it just no longer belongs to the reader. The loss is inside the joke itself (your money now lives in the shorter's wallet), so the trader laughs with the cookie instead of being lectured or pitied. The turn is fresh: no "rekt" slang, no liquidation pun, no advice about stop-losses — just the rueful image of your fortune moving house to the one person who bet against you. One line, 19 words, 100 characters.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
